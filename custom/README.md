# Кастомные треки

Файл `custom_v2.json` — место для СВОИХ треков подмены. Воркфлоу каждые 6 часов
(и по кнопке Run workflow) подтягивает оригинальный `list_v2.json` из
`Hazzz895/FckCensorData` и склеивает его с этим файлом в `list_v2_combined.json`,
которое приложение качает как основную базу. Оригинал при этом не трогается —
конфликтов при синке не бывает.

## Как добавить трек

1. Загрузи аудиофайл (без цензуры) в папку `tracks/`. Имя файла = id трека
   Яндекс.Музыки, например `25319594` (без расширения в имени не нужно —
   шаблон URL подставляет id целиком).

2. Добавь в `custom_v2.json` свой источник. Пример целиком:

```json
{
  "sources": [
    {
      "supportedVersions": ">0.0.0",
      "tracks": {
        "25319594": {
          "title": "Мама, я люблю (без цензуры)",
          "artist": "Anacondaz"
        }
      },
      "tracksStorages": [
        {
          "trackIds": [ { "id": 25319594 } ],
          "urlTemplate": "raw.githubusercontent.com/artikl95-source/FckCensorData/refs/heads/main/tracks/%%"
        }
      ]
    }
  ]
}
```

- `tracks.<id>` — подмена метаданных (необязательно): название, обложка, исполнитель.
  Именно эта запись включает маркер 🔥 у трека.
- `tracksStorages[].trackIds[].id` — числовой id трека Яндекс.Музыки.
  Можно перечислить несколько id, если один файл подходит нескольким версиям.
- `urlTemplate` — шаблон, `%%` заменяется на id трека.

3. Сделай push — воркфлоу пересоберёт `list_v2_combined.json`,
   приложение подхватит обновлённую базу при следующем запуске.
